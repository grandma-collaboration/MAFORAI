# Glossary

For whom: anyone reading pipeline v2 documentation who wants shared definitions.

This glossary defines the terms used by the canonical text, extractor, annotation, and INCEpTION export layers. The definitions are intentionally short so the reader can return quickly to the main workflow documents.

## CAS

CAS means Common Analysis Structure. It is the UIMA container that stores the document text and its annotations before serialization to XMI.

## Canonical Text

Canonical text is the single immutable string produced from a Circular subject, date, submitter, and body. All offsets in pipeline v2 point into this string.

## Certainty

Certainty is the tagset field that records how strong the annotation claim is. The current allowed values are `confirmed`, `candidate`, `tentative`, `rejected`, and `unclear`.

## GCN Circular

A GCN Circular is an astronomical report distributed through the Gamma-ray Coordinates Network. Pipeline v2 treats each Circular as a document that may contain event evidence.

## Label

Label is the tagset field that names the kind of evidence, such as `EVENT_IDENTITY` or `TRIGGER_TIME`.

## needs_review

`needs_review` marks an annotation that is useful but ambiguous. It tells the annotator that the machine found evidence but should not be trusted as final.

## Offset

An offset is a character position in `CanonicalDocument.rendered_text`. `span_start` and `span_end` are offsets.

## Round-Trip

A round-trip exports annotations to XMI, loads the XMI back, and checks that text, spans, and features match the original objects.

## Sofa

Sofa is the UIMA name for the subject of analysis, which is the document text inside the CAS. In this pipeline, `cas.sofa_string` is the canonical text.

## Span

A span is the substring selected by `span_start` and `span_end`. For example, in Circular `33130`, one trigger-time span is `02:16:38 UT on 1 Jan 2023`.

## Tagset

A tagset is a closed list of allowed annotation values. Pipeline v2 uses tagsets for `label`, `target`, and `certainty`.

## Target

Target is the tagset field that says what the evidence refers to, such as `event`, `counterpart`, `host`, or `instrument`.

## T0

T0 is a conventional name for the event reference time or trigger time. When a Circular says `T0 = ...`, the trigger-time extractor treats that as trigger context by itself.

## Trigger Time

Trigger time is the time at which the instrument or alert system detected or triggered on the event. Pipeline v2 annotates it as `TRIGGER_TIME`.

## XMI

XMI is an XML serialization format. INCEpTION can import UIMA CAS XMI XML 1.0 files generated by pipeline v2.
